# Key Hypothesis Stage Map

Use this reference when the user gives a vague business problem and you need to quickly decide which hypothesis layer is actually being discussed.

## Canonical Order

```text
需求假设 → 解决方案假设 → 商业模式假设 → 增长假设 → 壁垒问题
```

## Fast Mapping

| 用户常见说法 | 优先判断到哪一层 |
|---|---|
| 用户有没有这个痛点、这个场景值不值得做 | 需求假设 |
| 这个产品形态/服务方案能不能解决问题 | 解决方案假设 |
| 怎么定价、能不能赚钱、单元模型是否成立 | 商业模式假设 |
| 怎么获客、转介绍、复制、渠道 ROI | 增长假设 |
| 品牌、供应链、网络效应、组织能力是否形成优势 | 壁垒问题 |

## Discipline

- 如果需求假设没站住，不要直接把注意力放到增长。
- 如果解决方案还没跑通，不要用流量问题掩盖产品问题。
- 如果商业模式不成立，增长只会放大亏损。
